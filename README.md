# Eltűnő Számok

Téri-vizuális memória fejlesztő játék – jegyezd meg a számok helyét, majd kattints rájuk sorrendben!

Sima HTML + CSS + JavaScript, nincs build lépés és nem kell hozzá Node.

## Futtatás helyben

Nyisd meg az `index.html`-t böngészőben.

## Hosztolás GitHub Pages-en

1. Töltsd fel a repót GitHubra.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**
3. Branch: `main`, mappa: `/ (root)` → **Save**
4. Pár perc múlva elérhető: `https://<felhasználónév>.github.io/<repo-név>/`

A játék leírása: [docs/task](docs/task)
